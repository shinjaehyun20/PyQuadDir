# PyQuadDir v3.2.0

여러 파일을 끌어 옮길 때 선택이 풀리거나 주소창 Enter 뒤 상위 폴더로 이동하던 문제를 수정하고, Qt 엔진에 파일 관리 도구를 추가했습니다. v3.1.0 이후의 세션 종료·창 배치 수정도 포함합니다.

## 달라진 점

- 자세히·목록·타일·아이콘 보기에서 여러 파일의 드래그 선택을 유지합니다. 우클릭 메뉴와 경로 복사도 선택 전체를 사용합니다.
- 주소창에 경로를 붙여 넣고 Enter를 누르면 해당 폴더에 머뭅니다. 파일 경로라면 부모 폴더로 이동해 파일을 선택하며, 외부 프로그램을 바로 실행하지 않습니다.
- Qt의 **도구** 메뉴에 일괄 이름 바꾸기와 실행 취소, 패널 비교와 선택 복사, 폴더 용량, 해시·중복 찾기, 목록 내보내기, 하위 파일 모아보기, 탭 복제·잠금, 빠른 이동을 추가했습니다.
- 탭 잠금 상태의 닫기와 다중 선택 F2 동작을 수정했습니다. 좁은 창에서 도구는 메뉴 모음으로도 접근할 수 있습니다.
- 종료할 때 삭제된 Qt 위젯을 읽지 않고 세션을 저장하며, 창 위치·크기와 Inspector 표시를 복원합니다.
- Windows의 추가 도구 쓰기 작업에서 경로·대상 파일 보호를 강화했습니다. 빌드 시 외부 도구의 ICU DLL이 섞이지 않도록 패키징 환경을 정리했습니다.
- 소스의 `run_pyquaddir.bat`가 고정 개발 경로 대신 파일이 저장된 폴더에서 실행되며, `--self-test`는 바이트코드 파일을 만들지 않고 구문 오류를 종료 코드에 반영합니다.

## 다운로드와 실행

Windows x64용이며 Python을 별도로 설치할 필요가 없습니다. Microsoft Visual C++ v14 x64 Runtime **14.44.35211.0 이상**은 [Microsoft 공식 설치 파일](https://aka.ms/vc14/vc_redist.x64.exe)로 직접 설치합니다. 앱은 런타임 DLL·설치 프로그램을 포함하거나 자동 설치하지 않습니다.

| 첨부 파일 | 내용 |
| --- | --- |
| `PyQuadDir.exe` | 바로 실행할 Windows x64 파일 |
| `PyQuadDir-v3.2.0-Windows-x64.zip` | 실행 파일·설치 안내·프로젝트 라이선스·제3자 라이선스 고지 |
| `PyQuadDir-v3.2.0-sources.zip` | 앱 소스·빌드 안내·PyQt/Qt/Python 등 제3자 대응 소스 아카이브와 출처·해시 |
| `SHA256SUMS.txt` | 실행 파일과 두 ZIP의 SHA-256 |

실행 파일 SHA-256:

```text
F00E5B952326C56696C706A508128436424479A4451A1C6B052AB01F7DEEE162
```

실행 파일 크기는 **39,591,330바이트**, Windows 파일 버전은 **3.2.0.0**입니다. GitHub가 자동 생성하는 `Source code (zip)`은 실행 파일이 아닌 저장소 소스이며, 별도 대응 소스 ZIP과 구성이 다릅니다.

기존 사용자는 앱을 종료하고 실행 파일을 교체하면 됩니다. 홈 폴더의 `.pyquaddir_config.json`과 실행 폴더의 `.pyquaddir_session.json`은 개인 설정이므로 보존하고 배포 파일에 포함하지 마세요. 앱 자체는 업데이터를 설치하지 않습니다.

## 확인 범위와 제한

- v3.2.0 소스의 자동 테스트 82개와 같은 배포 실행 파일의 Qt GUI 자체 검사를 통과했습니다.
- 전체 도구 UI는 Qt 엔진에서 제공합니다. Tkinter에는 폴더 용량·해시·CSV 내보내기만 있습니다.
- 추가 도구의 이름 변경·선택 복사·내보내기는 경로 보호를 구현한 Windows에서 지원합니다. macOS/Linux에서는 해당 쓰기 작업을 거부합니다.
- 재귀 비교·용량·해시·중복 찾기는 현재 창에서 동기 실행하므로 대형 폴더나 네트워크 드라이브에서는 응답이 늦어질 수 있습니다.
- 자체 소스는 MIT 라이선스입니다. 실행 파일에 포함된 PyQt6는 GPLv3이며 Qt/Python 등에는 각자의 라이선스가 적용됩니다. 라이선스 고지 ZIP과 대응 소스 ZIP을 함께 보관해 주세요.
